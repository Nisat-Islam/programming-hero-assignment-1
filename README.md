# programming-hero-assignment-1

টাইপ ভার্সেস ইন্টারফেস
ইন্টারফেস মূলত তৈরি করা হয়েছে অব্জেক্ট এবং ক্লাস এর স্ট্রাকচার ডিফাইন করতে। এটির সবচেয়ে বড় সুবিধা হচ্ছে ডিক্লারেশন মার্জিং, অর্থাৎ একই নামে একাধিক ইন্টারফেস ডিক্লেয়ার করা হলে টাইপস্ক্রিপ্ট অটোমেটিক্যালি সেগুলোকে মার্জ করে দেয়। এছাড়াও একটি ইন্টারফেস আরেকটিকে এক্সটেণ্ড করতে পারে extends কীওয়ার্ড ব্যবহার করে।

টাইপের ক্ষেত্রে: টাইপ ব্যবহার করা হয় অব্জেক্ট, ইউনিয়ন, টুপল বা প্রিমিটিভ টাইপ ডিফাইন করার জন্য। টাইপে ডিক্লারেশন মার্জিং হয় না এবং টাইপকে এক্সটেণ্ড করতে হলে ইউনিয়ন বা ইনটারসেকশন (&) ব্যবহার করতে হয়।

keyof কীওয়ার্ড
keyof দিয়ে কোনো অব্জেক্টের সব প্রপার্টির নাম টাইপ হিসেবে পাওয়া যায়।
উদাহরণস্বরূপ, Student ইন্টারফেসে name, age, gpa আছে। keyof Student এর মান হবে "name" | "age" | "gpa"।
উদাহরণ কোড
interface Student { name: string; age: number; gpa: number }
type StudentKeys = keyof Student; 
এখানে StudentKeys টাইপের মান শুধুমাত্র name, age, অথবা gpa হতে পারবে।
অন্য কোনো মান, যেমন "roll", দিলে TypeScript এরর দেখাবে।
